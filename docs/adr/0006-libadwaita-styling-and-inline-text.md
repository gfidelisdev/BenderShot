# GNOME Libadwaita Styling and Inline Canvas Text Interaction

We decided to restyle the entire UI with official GNOME Libadwaita aesthetics (pill segmented toolbars, rounded capsule buttons, official Adwaita palettes with runtime Dark/Light mode switching) instead of default raw egui styles.

Furthermore, we replaced top-bar text staging with an interactive inline canvas text editor positioned directly at user click coordinates, rendering text with a contrast halo and vector TrueType typography supporting full Portuguese accented characters.
